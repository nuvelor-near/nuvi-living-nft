# NUVI form images

Drop the generated Hackathon NFT artwork here using these exact filenames:

- `basic.png`
- `form_a.png`
- `form_b.png`

Recommended source: square PNG, at least 1024×1024.

The web build copies these files to `/forms/`. The Living NFT contract derives dynamic media as:

`<collection.base_uri>/<form_id>.png`

Do not commit credentials, private source prompts or unrelated production assets here.
